GameNight Lua SDK v1 (gamenight-lua-v1). Generate a complete Lua 5.1 source file, not a patch. New registration requires save/validate/restart/reconnect. Only these APIs and basic Lua are available; no core, io, os, require, load, debug, metatables, coroutine, pcall or filesystem/network access.
Persistent namespace: gamenight_custom. Use stable lowercase item IDs (a-z, digits, underscore, max32). Names passed to SDK item functions are short IDs.
Register nodes, tools, tick/join callbacks and checks ONCE at the top level, never inside a callback. Registration is closed after startup.
gn.node(id, {description=string, color="#RRGGBB", light=0..14}) registers a diggable solid cube using built-in texture; light defaults0.
gn.tool(id, {description=string,color="#RRGGBB"}, function(player, pointed_position_or_nil) ... end) registers a new usable item. player is an opaque string, not a PlayerRef. Callback runs when the player uses the tool.
gn.on_join(function(player) ... end); gn.give_once(player,id,count1..16) grants own registered item once per player/item, including reconnects.
gn.on_tick(function(dt) ... end) registers a callback called every0.1seconds; dt is seconds capped0.5. Up to8 callbacks, finite work only.
gn.players() returns array of connected player IDs. gn.pos(player), gn.look(player), gn.velocity(player) return {x,y,z}. gn.controls(player) returns {jump,sneak,aux1,dig,place} booleans. gn.wielded(player) returns full item name. gn.push(player,{x,y,z}) adds velocity, each component -20..20.
gn.near(pos,radius0..8) returns player IDs within radius. gn.node_at(pos) returns full node name, only near a player. gn.place(pos,id) places own registered node only in air or own content within8blocks of a player. Returns boolean; never overwrites ordinary terrain. gn.remove(pos) removes own content only, same radius. Round positions with math.floor(value+0.5).
gn.get(key,default) and gn.set(key,value) persist scalar number/boolean/string across restart and edits (max128 keys, key64chars,value1024chars). Use per-player keys when appropriate. gn.say(player,text) sends chat (max160chars). gn.emit(label,number) records bounded diagnostic counters for verification. gn.check(function() assert(...) end) registers a pure logic self-test, run at startup and validation.
Environment: assert,error,type,tonumber,tostring,ipairs,pairs,next; math.abs,min,max,floor,ceil,sqrt,sin,cos,pi,random; table.insert/remove; limited string.len/sub/lower/upper/byte/find (find is plain). No other string methods. Keep existing item kinds when reusing an ID. Max128 retained definitions per world,16 active definitions,8 tick callbacks,8 joins,8 checks; 100000 instructions and32 game operations per callback. All callbacks are guarded: errors disable the generated behavior, not the world. Persistent item definitions remain inert when removed by an edit/undo, so existing nodes/items do not become unknown.
Compose original mechanics with Lua state, functions, conditions and callbacks. Do not assume entities, meshes, arbitrary assets, damage or unrestricted terrain APIs. Preserve existing code/content for follow-up changes unless removal is requested. Explain restart and any unsupported part; never claim success before host confirmation.

Lua syntax examples (adapt to the requested behavior):
Velocity is a named table: gn.push(p,{x=2,y=1,z=0}). Never use an array such as {2,1,0}.
Proximity: for _,other in ipairs(gn.near(gn.pos(p),3)) do if other~=p then ... end end. gn.players() alone does not filter by distance.
Persistent counter: local count=gn.get("visits",0); gn.emit("visits",count). On an event: count=count+1; gn.set("visits",count); gn.emit("visits",count). Do not reset stored state to zero at startup.
Cooldown: local now=0; local next_use={}; gn.on_tick(function(dt) now=now+dt end). In the item's use callback: if now<(next_use[p] or 0) then return end; next_use[p]=now+0.5. This becomes available again after half a second and uses no wall clock.
